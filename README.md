## Локальный запуск

### 1. Клонировать репозиторий

```bash
git clone <repository-url>
```

### 2. Перейти в директорию проекта

```bash
cd max-chat-test-task
```

### 3. Установить зависимости

```bash
npm install
```

### 4. Запустить проект

```bash
npm run dev
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:5173
```
